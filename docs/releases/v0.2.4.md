# SpeakHub v0.2.4

## 新增 Gemini 网页对话

- 主窗口新增「Gemini 网页」，可与 ChatGPT 网页、API 直连自由选择。
- 接入 AI Studio 的 Gemini 3.8 Live，支持语音和文字对话，无需填写 Gemini API Key。
- 支持在应用内打开 Gemini，也可隐藏到后台继续练习，实时显示双方字幕并保存对话。
- 新增 Google 登录引导，使用专属浏览器完成登录后返回应用，保留登录状态。

## 结束与复盘优化

- 点击「结束并生成复盘」后立即静音 Gemini，并断开对话，避免结束后继续播放语音。
- Gemini 练习复盘统一使用设置中配置的大模型 API，支持纠错、能力评估和历史记录重新复盘。

## 语音体验优化

- 阿里语音识别切换至 Paraformer，支持英文优先与中英混合识别。
- 优化英文识别参数、语音合成流式播放和音频预取，减少句子之间的等待。

Windows x64 安装包：`SpeakHub-0.2.4-Setup.exe`。

覆盖安装可保留原有设置和练习记录。
