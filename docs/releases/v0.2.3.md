# SpeakHub v0.2.3

## 新增功能

- 设置中新增语音输入设备选择，支持系统默认和指定麦克风，选择自动保存。
- 麦克风检测、API 直连和 ChatGPT 语音统一使用所选输入设备。
- 右上角新增麦克风开关，支持手动点击、F8 和设置中的自定义快捷键；练习前也可以设置麦克风状态。

## 修复与优化

- 修复 ChatGPT 使用通信麦克风而设置检测使用默认麦克风时，出现“能听到回复、说话却没有反应”的问题。
- 优化 ChatGPT 首次启动的发送确认与自动恢复，减少需要再次点击开始的情况，并防止重复输入和重复提交提示词。
- 修复 ChatGPT 页面切换或暂时读取失败后字幕采集停止的问题，保留启动期间收到的首条字幕。
- 修复 ChatGPT 页面遮挡主界面及窗口按钮的问题，支持后台语音运行和连接页切换。
- 修复阿里语音识别静默断线与任务失败后的恢复，持续提交音频并自动重连。
- 完善上一轮 ChatGPT 练习聊天的清理，通过正式会话地址定位，本地练习记录和复盘继续保留。

Windows x64 安装包：`SpeakHub-0.2.3-Setup.exe`。
